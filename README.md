**# 🐍 Python-MySQL Database Connectivity**



**## 📌 Project Overview**



**This project demonstrates how to connect Python with a MySQL database and perform basic database operations using the `mysql-connector-python` library.**



**It covers database creation, table creation, inserting records, retrieving data, and filtering records using SQL queries.**



**## 🎯 Project Objectives**



**- Establish a connection between Python and MySQL.**

**- Create a database and table.**

**- Insert single and multiple records.**

**- Retrieve records from the database.**

**- Filter records using parameterized SQL queries.**



**## 🛠️ Technologies Used**



**- Python**

**- MySQL**

**- MySQL Connector**

**- Jupyter Notebook**



**## ✨ Key Features**



**- Database creation (`db\_demos`)**

**- Table creation (`Person`)**

**- Single record insertion**

**- Multiple record insertion using `executemany()`**

**- Fetch all records using `SELECT`**

**- Search records by person name**

**- Secure password input using `getpass` is not implemented; replace the placeholder with your own MySQL password before running.**



**## 🗂️ Database Structure**



**\*\*Database:\*\* `db\_demos`**



**\*\*Table:\*\* `Person`**



**| Column | Data Type    |**

**| ------ | ------------ |**

**| p\_name | VARCHAR(50)  |**

**| age    | INT          |**

**| salary | DECIMAL(8,2) |**



**## ⚙️ Installation \& Setup**



**1. Install Python and MySQL Server.**



**2. Install the required Python library:**



&#x20;  **```bash**

&#x20;  **pip install mysql-connector-python**

&#x20;  **```**



**3. Open the Jupyter Notebook.**



**4. Replace `YOUR\_MYSQL\_PASSWORD` with your own MySQL password.**



**5. Run the notebook cells in order.**
